# Ukeplan mot JUUL

Ukeplanen fra 29. november til 14. desember: hvilke fag og hvor mange timer hver dag, og når eksamenene er. MBF øves i MBF-appen, kjemi med oppgaver i kompendiet og fysikk med oppgaver fra faglærer.

Adresse: https://felixeriksen04-maker.github.io/Eksamensplan26/

## Legg til på hjemskjermen

- **iPhone (Safari):** Åpne adressen → **Del** → **Legg til på Hjem-skjerm**.
- **Android (Chrome):** Åpne adressen → menyen (⋮) → **Installer app** eller **Legg til på startskjermen**.

Ligger appen allerede på hjemskjermen uten bildet, må du slette den og legge den til på nytt. Telefonen henter ikonet bare når du legger appen til.

## Filer

Alle filene ligger i rotmappen. Da virker de også når de lastes opp med **Add file → Upload files**, der mapper ikke blir med.

- `index.html`, `app.js`, `styles.css`: appen
- `plan.js`: planen (timer per fag per dag, eksamener og merknader). Endre planen her.
- `manifest.webmanifest`, `apple-touch-icon.png`, `icon-192.png`, `icon-512.png`, `favicon-32.png`: navn og ikon på hjemskjermen
